## 왜 1D 필터가 마법 같나

### 원리
```
HERMES v7/v8은 4H 레짐 + 1H 시그널만 봄.
→ 4H가 TRENDING_UP인데 실제 1D는 하락 중 → LONG 진입 → SL
→ 2026-04-18 3연패가 정확히 이 메커니즘

v9는 1D EMA10 방향도 체크:
→ 1D EMA10 상승 중? LONG 허용
→ 1D EMA10 하락 중? LONG 차단
→ "큰 그림"이 맞는 방향으로만 거래
```

### 04-18 예시
당일 BTC 1D EMA10은 **상승 중이었는지 하락 중이었는지 검증**:
- 만약 하락 중이었다면 → v9는 3 LONG 전부 차단
- 실전 10일 백테스트 +$110 vs v8 +$88 = **이 필터링 효과 반영**
