# HERMES 백테스팅 아카이브

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

HERMES 자동매매 시스템의 백테스트 결과와 분석 노트 모음.
실제 운영 코드와 백테스트 스크립트는 [hermes](https://github.com/deltaomega02/hermes) 저장소의 `backtest/`에 있다.

## 구조

```
HERMES_백테스팅/
├── README.md   ← 이 파일 (버전 요약 인덱스)
├── ideas/      ← 아이디어/문제점 노트 (버전 무관, 누적)
└── vN/         ← 버전별 백테스트 결과 (v2, v3, ... 추가)
```

새 백테스트는 `v4/`, `v5/` 식으로 하위 폴더를 추가한다.
각 vN은 독립적으로 보존하고, 덮어쓰지 않는다.

### v5 — 쿨다운 유무 비교 (2026-04-12)

- 목적: 연패 쿨다운(2연패→60분, 3연패→당일중단)이 정말 필요한가?
- **결론: 쿨다운이 수익을 절반으로 깎고 있었음. 제거가 정답.**
- 쿨다운 있음 대비 **쿨다운 없음이 순이익 2.2배** (DD도 28.0% → 26.8%로 개선)
- 원인: 추세 풀백 전략에서 SL 후 다음 진입이 오히려 좋은 자리. 쿨다운이 "반등 진입"을 통째로 건너뜀.
- **2026-04-12 GCP 반영 완료**: `config/settings.py`, `core/risk_manager.py` 교체
- 긴급 HIGH_VOL 쿨다운(시장 급변 방어)은 유지 — 별개 메커니즘
- 코드: `HERMES/backtest/v5_cooldown_compare.py`
- 결과: `v5/v5_cooldown_compare.json`

### v4 — 최소 시드 분석 Shared-Balance (2026-04-12)

- 목적: "무난히 수익 나는 최소 시드" 파악
- **엔진**: 실제 HERMES 구조 그대로 (3코인 공유 잔고, MAX_SIMULTANEOUS=2 전역, 단일 타임라인). v3_engine의 독립 백테스트는 소액 시드에서 낙관적이었음 → 폐기.
- 설정: v3 BEST + trailing 1.5/0.3 + funding ON. 서버비 ₩1,150/일 일별 차감. 파산선 $15.
- **두 시나리오 비교:**
  - **A) 완전 자동**: 2022~2026 전 기간 HERMES 자체 운영
  - **B) 수동 감독**: 2023년 저변동 구간 수동 중단 (매일 텔레그램 감독)

**시나리오 A (자동):**
| 시드 | DD | 결과 |
|---|---|---|
| $100 | 86% | 파산 2022-07-13 |
| $200 | 95% | 파산 2024-01-21 |
| $300 | 56% | 생존 위험 |
| $500 | 50.6% | 경계 |
| **$600** | **49.6%** | **안전권** |
| $1000 | 48.0% | 양호 |

**시나리오 B (수동 감독):**
| 시드 | DD | 결과 |
|---|---|---|
| $200 이하 | 90%+ | 파산 (2022년에 사망) |
| $300 | 44.3% | 생존 |
| **$400** | **29.6%** | **안정권 진입** |
| $500 | 26.8% | 안정 |
| $600+ | 26.7% | 수렴 |

**결론:**
- **절대 금지**: $200 이하 (감독해도 파산)
- **수동 감독 시 최소**: $400 (DD 30% 이하)
- **자동 운영 시 최소**: $600 (DD 50% 경계)
- **여유**: $1,000+

**파일:**
- 엔진: `HERMES/backtest/v4_shared_engine.py`
- 러너: `HERMES/backtest/v4_seed_sweep.py`
- 결과: `v4/v4_seed_sweep.json`

## ideas/

- `01_문제점_및_개선방안.md` — 2026-04-02 작성. LONG 약점, SOL LONG 제거, 자동 방어 모드, ATR 적응형 SL, 서버비 최적화 등.

## 운영 규칙

- 파라미터 임의 변경 금지 — 백테스트/Optuna 검증 후에만 반영
- 레버리지 증가 금지
- 횡보 전략(RANGE_REVERSION) 재활성화 금지 (v2 기준 -93% 확인)
- 5분봉 전환 금지 (수수료 구조상 불가)
- 검증 없이 시드 증액 금지
